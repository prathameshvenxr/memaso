Memory that knows when it stopped being true.

Memaso stores what was said, dates the facts inside it, and gives your agent a small block for its prompt. A newer statement closes the older one. No model required.

Try it. Type like a user would.

What the prompt gets 

          

          

          
Runs in your browser: a port of the engine's rules path, with no model and no network. The engine itself is Python on Postgres.

        

      

    


    

      

        

          
Every turn is kept twice.

          
Once as it was said, once as facts with dates. Recall reads both, so the exact words are never lost and the current value is never ambiguous.

        

        

          

            
Verbatim

            
The words, as they were said
Each turn is cut into passages of about 800 characters and embedded on your own machine. Nothing is lost to a summary, and search needs no model.

            
user: Budget is 50k. I want weekly reports in INR.

          

          

            
Facts

            
The statements inside them, with dates
Plain statements become facts with valid_from and valid_to. A newer one closes the older, and the history stays for as_of questions.

            
Budget is 50k  closed feb 1
the budget is 80k  current

          

          

            
Now

            
One block for the prompt
Search fuses both layers, blanks out superseded words inside old text, and packs the result to the token budget you set. Recalled text is escaped and labelled as untrusted data.

            
<memory kind="fact">the budget is 80k</memory>

          

        

      

    


    

      

        

          
Recall costs no model tokens.

          
Embedding, search and the judging of plain statements all run on your own machine. A model is used only where you switch one on, or where the text is genuinely ambiguous.

A model only when it has to.

          
Deciding whether a new sentence updates a stored one is the one place a model helps. Memaso settles the clear cases itself and asks only about the rest.

        

        

          
Rules
Plain statements
“The budget is 80k” has a subject, a verb and a value. Same attribute is an update, a different attribute is new, and an exact opposite preference is a contradiction.

          
Your model
Ambiguous free text
“Monthly budget” against “budget” may or may not be the same thing. If you pass llm=your_call it is asked once, with one candidate and five neighbours. It is the model you already run, on your keys.

          
Neither
No model, no guess
Without a model both facts stay and the unsure one is marked. Memaso keeps two facts before it overwrites a true one.

        

      

    


    

      

        

          
Memory that looks after itself.

          
None of this calls a model, and none of it runs while a request waits.

        

        

          
Updates in any phrasing
“We raised our monthly budget to 80k” closes “Budget is 50k”. So do “has been updated to” and “went up to”. A daily figure beside a monthly one is kept apart: the numbers have to be the same size.

          
Forgetting without losing
Each fact has an importance that grows when it is restated and fades with disuse. consolidate merges duplicates and archives the cold, low-value ones. They are kept, readable and restorable, and their vectors are freed.

          
Names link facts
Ask what Priya should hit and the answer comes through Acme: the account she leads, and its CPA target. One indexed lookup per question, and nothing when the question names nobody.

The datasets are synthetic and template-based, and the model-driven paths are tested with scripted answers, not a live provider. The limits are written down.

      

    


    

      

        

          
Swap anything.

          
Every dependency sits behind a port and is chosen in configuration. Core code never imports a vendor SDK, and a test fails the build if it does.

        

        

          
Language modelnone, your own call, Anthropic, OpenAI, any compatible server

          
Embeddingslocal ONNX (free), OpenAI

          
StorePostgres with pgvector, in its own schema

          
Queuein-process, Redis for replicas

          
Auth and parserAPI keys, plain text

          
Yoursadapter: "package.module:factory", certified by the contract tests
